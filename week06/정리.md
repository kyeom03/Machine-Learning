| 기법 | 핵심 아이디어 | 해결하려는 문제 |
|---|---|---|
| ResNet | 잔차 연결 (Residual Connection) | 깊은 신경망의 학습 어려움 완화 |
| SENet | 채널별 중요도 조절 (Channel Attention) | 중요한 특징 채널 강조 |
| Inception | 여러 크기의 필터를 병렬로 사용 | 다양한 크기의 특징 추출 |
| Depthwise Convolution | 채널별로 독립적인 합성곱 수행 | 연산량 및 파라미터 수 감소 |
| CBAM | 채널 어텐션 + 공간 어텐션 | 중요한 특징 채널과 위치 강조 |

## 1. ResNet (Residual Network)

### 핵심 개념: Skip Connection

ResNet은 신경망을 깊게 쌓을수록 학습이 어려워지는 문제를 완화하기 위해 제안된 구조이다.

일반적인 CNN은 입력 `x`를 여러 합성곱 계층에 통과시켜 결과 `H(x)`를 만든다. ResNet은 입력 `x`를 출력에 직접 더하는 잔차 연결(Residual Connection)을 사용한다.

**수식**

`y = F(x) + x`

- `x`: 입력 특징
- `F(x)`: 합성곱 계층 등이 학습한 잔차(Residual)
- `y`: 최종 출력

**동작 구조**

```text
입력 x
 ├── Conv → BatchNorm → ReLU → Conv → BatchNorm ──┐
 └──────────────── Skip Connection ────────────────┤
                                                   ↓
                                              F(x) + x
                                                   ↓
                                                 출력
```

### 왜 필요할까?

- **기울기 소실 완화:** 역전파 시 기울기가 전달될 수 있는 직접적인 경로를 제공한다.
- **깊은 네트워크 학습 개선:** 많은 계층을 쌓을 때 발생하는 최적화 어려움을 완화한다.
- **잔차 학습:** 입력 자체보다 입력에서 변화해야 할 부분인 `F(x)`를 학습한다.

대표적인 모델은 ResNet-18, ResNet-50, ResNet-101 등이 있다.

> 쉽게 말하면, 기존 정보를 그대로 전달하는 지름길을 만들어 깊은 신경망도 학습하기 쉽게 하는 구조이다.

## 2. SENet (Squeeze-and-Excitation Network)

### 핵심 개념: 채널(Channel)별 중요도 학습

CNN의 특징 맵(Feature Map)은 여러 채널로 이루어져 있다. 각 채널은 모서리, 질감, 형태 등 서로 다른 특징에 반응할 수 있다.

SENet은 각 채널의 중요도를 학습하고 중요도에 따라 채널의 값을 조절한다.

### 동작 과정

입력 특징 맵: `H × W × C`

1. **Squeeze**
   - Global Average Pooling을 사용해 각 채널의 공간 정보를 하나의 값으로 요약한다.

2. **Excitation**
   - 작은 신경망을 이용해 채널별 중요도 가중치를 계산한다.

3. **Scale**
   - 계산된 가중치를 각 채널에 곱한다.

**수식**

`X̃_c = s_c × X_c`

- `X_c`: c번째 채널의 특징 맵
- `s_c`: c번째 채널의 중요도 가중치
- `X̃_c`: 가중치가 적용된 특징 맵

일반적으로 `s_c`는 0과 1 사이의 값이다.

**예시**

- 채널 A: 0.9 → 강하게 강조
- 채널 B: 0.2 → 상대적으로 억제
- 채널 C: 0.7 → 비교적 강조

### 장점과 특징

- 중요한 특징 채널을 자동으로 학습한다.
- 기존 CNN 블록에 비교적 쉽게 추가할 수 있다.
- 추가 연산과 파라미터가 필요하지만, 채널별 특징을 효과적으로 조절할 수 있다.

> 쉽게 말하면, 여러 특징 채널 중 어떤 특징을 더 중요하게 볼지 결정하는 기법이다.

## 3. Inception

### 핵심 개념: 여러 크기의 필터를 병렬로 사용

일반적인 CNN은 특정 크기의 합성곱 필터를 사용해 특징을 추출한다. 하지만 이미지에는 작은 특징과 큰 특징이 함께 존재한다.

- **작은 특징:** 모서리, 가는 선, 세부 질감
- **큰 특징:** 물체의 윤곽, 넓은 형태

Inception은 서로 다른 연산을 병렬로 수행하고 그 결과를 결합한다.

### 동작 과정

대표적인 초기 Inception 모듈의 구조는 다음과 같다.

```text
                    입력 특징 맵
                         |
          ┌──────────────┼──────────────┐
          |              |              |
       1×1 Conv      1×1 → 3×3      1×1 → 5×5
          |              |              |
          └──────────────┼──────────────┘
                         |
                   Pooling → Conv
                         |
                         ↓
              채널 방향으로 결합
               (Concatenation)
```

서로 다른 경로의 출력은 공간 크기를 맞춘 뒤 채널 방향으로 연결한다.

참고로 `1×1 Conv`는 채널 수를 줄여 `3×3`이나 `5×5` 합성곱의 연산량을 줄이는 데 활용될 수 있다.

### 장점과 특징

- 서로 다른 크기의 특징을 동시에 추출한다.
- 다양한 크기의 물체와 패턴을 처리하는 데 유리하다.
- 병렬 경로를 사용하므로 구조가 복잡해질 수 있다.

대표적인 모델은 GoogLeNet(Inception v1), Inception v3, Inception-v4 등이 있다.

> 쉽게 말하면, 여러 종류의 렌즈로 동시에 사진을 관찰한 뒤 각 렌즈가 찾은 정보를 합치는 구조이다.

## 4. Depthwise Convolution

### 핵심 개념: 채널마다 독립적으로 합성곱 수행

일반적인 합성곱(Standard Convolution)은 입력의 모든 채널을 함께 사용해 출력 특징을 만든다.

반면 Depthwise Convolution은 입력 채널마다 별도의 필터를 적용해 공간적인 특징을 추출한다. 이 단계에서는 채널 간 정보를 직접 섞지 않는다.

**예시**

입력이 `H × W × 3`인 RGB 이미지라면 다음과 같이 처리한다.

- R 채널 → R 채널의 공간적 특징 추출
- G 채널 → G 채널의 공간적 특징 추출
- B 채널 → B 채널의 공간적 특징 추출

### 연산량 및 파라미터 비교

입력 채널 수를 `C_in`, 출력 채널 수를 `C_out`, 필터 크기를 `K × K`라고 하자.

**일반 합성곱의 파라미터 수**

`K² × C_in × C_out`

**Depthwise Convolution의 파라미터 수**

`K² × C_in`

위 식은 채널마다 필터 하나를 사용하는 경우이며, 편향과 정규화 계층은 제외한다.

### Depthwise Separable Convolution과의 차이

두 개념은 관련이 있지만 동일하지 않다.

1. **Depthwise Convolution**
   - 각 채널 안에서 공간적 특징을 추출한다.

2. **Pointwise Convolution (`1×1 Conv`)**
   - 채널 간 정보를 결합하고 원하는 출력 채널 수를 만든다.

두 단계를 결합한 구조를 **Depthwise Separable Convolution**이라고 한다.

**예시: `3×3` 필터, 입력 채널 32개, 출력 채널 64개**

| 방식 | 파라미터 수 |
|---|---:|
| 일반 합성곱 | `3² × 32 × 64 = 18,432` |
| Depthwise + Pointwise | `3² × 32 + 32 × 64 = 2,336` |

편향과 정규화 계층을 제외하면 위 조건에서 합성곱 파라미터 수가 약 87.3% 감소한다.

### 장점과 특징

- 연산량과 파라미터 수를 줄이는 데 유리하다.
- 모바일 및 엣지 디바이스처럼 자원이 제한된 환경에 적합하다.
- MobileNet 계열에서 핵심적으로 사용된다.

> 쉽게 말하면, 채널별로 먼저 따로 분석한 뒤 `1×1 Conv`로 분석 결과를 결합하는 방식이다.

## 5. CBAM (Convolutional Block Attention Module)

### 핵심 개념: 채널 어텐션 + 공간 어텐션

CBAM은 CNN이 어떤 특징을 중요하게 볼지(Channel Attention), 이미지의 어느 위치를 중요하게 볼지(Spatial Attention)를 함께 학습하는 어텐션 모듈이다.

SENet이 주로 채널 중요도를 조절하는 반면, CBAM은 채널과 공간적 위치를 모두 고려한다.

### 동작 과정

CBAM은 일반적으로 두 단계를 순차적으로 적용한다.

**입력 특징 맵 `F`**

1. **Channel Attention — 어떤 채널이 중요한가?**
   - Global Average Pooling과 Global Max Pooling으로 채널 정보를 요약한다.
   - MLP를 이용해 채널별 중요도 가중치를 계산한다.

2. **Spatial Attention — 어떤 위치가 중요한가?**
   - 채널별 평균과 최댓값을 계산한다.
   - 두 결과를 결합한 뒤 합성곱을 적용해 공간 가중치를 계산한다.

**결과:** 채널과 공간적 위치의 중요도가 반영된 특징 맵

### 두 어텐션의 역할

- **Channel Attention:** 물체 인식에 유용한 특징 채널을 강조한다.
- **Spatial Attention:** 중요한 특징이 나타나는 공간적 위치를 강조한다.

**예시: 강아지 이미지 분류**

- Channel Attention은 털이나 귀의 형태를 표현하는 특징 채널을 강조할 수 있다.
- Spatial Attention은 강아지의 얼굴이 있는 영역을 강조할 수 있다.

이는 이해를 돕기 위한 예시이며, 실제로 강조되는 특징은 학습 데이터와 모델에 따라 달라진다.

### SENet과 CBAM 비교

| 비교 항목 | SENet | CBAM |
|---|---|---|
| 채널 어텐션 | 사용 | 사용 |
| 공간 어텐션 | 기본 구조에서 사용하지 않음 | 사용 |
| 주요 목적 | 중요한 채널 강조 | 중요한 채널과 위치 강조 |
| 일반적인 구조 | 채널 가중치 계산 후 적용 | 채널 어텐션 후 공간 어텐션 적용 |

> 쉽게 말하면, SENet이 어떤 종류의 특징을 볼지 결정한다면, CBAM은 어떤 특징을 볼지뿐 아니라 어디를 볼지도 결정하는 방식이다.

## 6. 다섯 가지 기법 한눈에 비교하기

| 기법 | 핵심 아이디어 | 해결하려는 문제 | 주요 키워드 |
|---|---|---|---|
| ResNet | 잔차 연결로 입력을 출력에 더함 | 깊은 네트워크의 학습 어려움 완화 | Skip Connection |
| SENet | 채널별 중요도 학습 | 중요한 특징 채널 강조 | Channel Attention |
| Inception | 다양한 연산 경로를 병렬로 사용 | 여러 크기의 특징 추출 | Multi-scale Features |
| Depthwise Convolution | 채널별로 독립적인 합성곱 수행 | 연산량 및 파라미터 수 감소 | Efficient Convolution |
| CBAM | 채널 및 공간 어텐션 결합 | 중요한 특징 채널과 위치 강조 | Channel + Spatial Attention |

### 핵심 요약

- **ResNet:** 깊은 신경망의 학습을 돕는다.
- **SENet:** 중요한 특징 채널을 강조한다.
- **Inception:** 다양한 크기의 특징을 동시에 추출한다.
- **Depthwise Convolution:** 합성곱의 연산 효율을 높인다.
- **CBAM:** 중요한 특징 채널과 공간적 위치를 함께 강조한다.
