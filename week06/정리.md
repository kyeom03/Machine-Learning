CNN 주요 구조 및 기법 정리
1. ResNet (Residual Network)
핵심 개념: Skip Connection (잔차 연결)

ResNet은 신경망이 깊어질수록 학습이 어려워지는 문제를 해결하기 위해 제안된 구조이다.

2. SENet (Squeeze-and-Excitation Network)
핵심 개념: Channel Attention

SENet은 CNN의 특징 맵에서 각 채널의 중요도를 학습하고, 중요도에 따라 채널별 특징을 강조하거나 억제하는 기법이다.

CNN의 각 채널은 모서리, 질감, 형태 등 서로 다른 특징에 반응할 수 있다. SENet은 이러한 채널 중 어떤 채널이 중요한지 자동으로 학습한다.

1. Squeeze

Global Average Pooling(GAP)을 사용해 각 채널의 공간 정보를 하나의 값으로 요약한다.

입력 특징 맵의 크기가 H x W x C라면 출력 크기는 1 x 1 x C가 된다.

2. Excitation

작은 완전연결 신경망(FC)을 사용해 채널별 중요도를 계산한다.

일반적으로 ReLU와 Sigmoid 함수를 사용한다.

장점
중요한 특징 채널을 자동으로 강조
기존 CNN 구조에 비교적 쉽게 적용 가능
적은 추가 비용으로 모델 성능을 개선할 수 있음

핵심 요약: 어떤 특징 채널이 중요한지 학습하고, 채널별 가중치를 적용한다.

3. Inception
핵심 개념: Multi-scale Feature Extraction

Inception은 서로 다른 크기의 합성곱 필터와 여러 연산 경로를 병렬로 사용해 다양한 크기의 특징을 추출하는 구조이다.

이미지에는 작은 특징과 큰 특징이 함께 존재한다.

작은 특징: 모서리, 가는 선, 세부 질감
큰 특징: 물체의 윤곽, 넓은 형태

Inception은 여러 경로에서 특징을 추출한 후 결과를 결합한다.

동작 과정
               Input
                 |
       +---------+---------+
       |         |         |
       v         v         v
    1x1 Conv  3x3 Conv  5x5 Conv
       |         |         |
       |      (1x1 Conv   (1x1 Conv
       |       for         for
       |       reduction)  reduction)
       |         |         |
       +---------+---------+
                 |
          Concatenation
                 |
               Output


초기 Inception 모듈에는 Pooling 경로도 포함될 수 있다.

주요 구성 요소
1x1 Convolution: 채널 정보를 결합하고 채널 수를 줄이는 데 활용
3x3 Convolution: 비교적 작은 지역의 특징 추출
5x5 Convolution: 더 넓은 영역의 특징 추출
Pooling: 공간적인 특징을 요약
Concatenation: 각 경로의 결과를 채널 방향으로 결합

실제 Inception 구조에서는 연산량을 줄이기 위해 3x3 또는 5x5 합성곱 앞에 1x1 합성곱을 배치할 수 있다.

장점
다양한 크기의 특징을 동시에 추출
여러 크기의 물체와 패턴을 처리하는 데 유리
병렬 경로를 통해 풍부한 특징 표현 학습 가능
대표 모델
GoogLeNet (Inception v1)
Inception v2
Inception v3
Inception-v4

핵심 요약: 여러 크기의 필터를 병렬로 사용하고, 각 경로에서 추출한 특징을 결합한다.

4. Depthwise Convolution
핵심 개념: 채널별 독립적인 합성곱

일반적인 합성곱(Standard Convolution)은 입력의 여러 채널을 함께 사용해 출력 특징을 생성한다.

반면 Depthwise Convolution은 입력 채널마다 별도의 필터를 적용한다. 이 단계에서는 채널 간 정보를 직접 결합하지 않는다.

예를 들어 RGB 이미지의 경우 다음과 같이 처리한다.

Input RGB Image
      |
      +---- R Channel ----> Convolution
      |
      +---- G Channel ----> Convolution
      |
      +---- B Channel ----> Convolution

입력 채널 수를 C_in, 출력 채널 수를 C_out, 필터 크기를 K x K라고 가정한다.

5. CBAM (Convolutional Block Attention Module)
핵심 개념: Channel Attention + Spatial Attention

CBAM은 채널과 공간적 위치에 대한 어텐션을 순차적으로 적용하는 모듈이다.

SENet이 채널별 중요도에 집중하는 반면, CBAM은 채널별 중요도와 공간적 위치의 중요도를 모두 고려한다.

동작 과정
Input Feature Map
        |
        v
Channel Attention
        |
        v
Feature Refinement
        |
        v
Spatial Attention
        |
        v
Feature Refinement
        |
        v
Output Feature Map

1. Channel Attention

어떤 채널이 중요한지 학습한다.

일반적인 CBAM 채널 어텐션은 다음 과정을 사용한다.

Global Average Pooling
Global Max Pooling
공유 MLP를 통한 특징 처리
결과 결합 및 Sigmoid
채널별 가중치 적용

목적: 중요한 특징 채널을 강조한다.

2. Spatial Attention

특징 맵의 어느 위치가 중요한지 학습한다.

일반적인 CBAM 공간 어텐션은 다음 과정을 사용한다.

채널 방향 평균 연산
채널 방향 최댓값 연산
두 결과를 채널 방향으로 결합
합성곱과 Sigmoid를 적용
공간별 가중치 적용

목적: 중요한 공간적 위치를 강조한다.

예시

강아지 이미지를 분류하는 상황을 가정하면 다음과 같다.

Channel Attention: 털이나 귀의 형태를 표현하는 특징 채널을 강조
Spatial Attention: 강아지의 얼굴 등 중요한 특징이 있는 위치를 강조

이는 이해를 위한 예시이며, 실제로 강조되는 특징은 학습 결과에 따라 달라진다.

SENet과 CBAM 비교
비교 항목	SENet	CBAM
Channel Attention	사용	사용
Spatial Attention	기본 모듈에 없음	사용
주요 목적	채널 중요도 조절	채널 및 공간 중요도 조절
연산 순서	채널 가중치 계산	채널 어텐션 후 공간 어텐션
특징	상대적으로 단순한 어텐션	두 종류의 어텐션 결합

핵심 요약: 어떤 특징이 중요한지뿐만 아니라, 그 특징이 이미지의 어느 위치에서 중요한지도 학습한다.

6. 다섯 가지 기법 비교
기법	핵심 아이디어	주요 목적	키워드
ResNet	Skip Connection	깊은 네트워크 학습 개선	Residual Learning
SENet	채널별 가중치	중요한 채널 강조	Channel Attention
Inception	여러 크기의 필터 병렬 사용	다양한 특징 추출	Multi-scale Features
Depthwise Convolution	채널별 독립적인 합성곱	연산량 감소	Efficient Convolution
CBAM	채널 + 공간 어텐션	중요한 특징과 위치 강조	Channel + Spatial Attention
7. 실제 모델에서의 조합

이 기법들은 목적이 다르기 때문에 하나의 모델에서 조합할 수 있다.

ResNet + SENet

ResNet의 잔차 블록에 SE 모듈을 추가해 채널별 중요도를 학습한다.

대표적인 예시는 SE-ResNet이다.

ResNet + CBAM

ResNet의 특징 추출 과정에 CBAM을 추가해 중요한 채널과 공간적 위치를 강조한다.

Depthwise Convolution + CBAM

Depthwise Convolution으로 연산량을 줄이면서 CBAM으로 특징을 정교하게 강조하는 구조를 설계할 수 있다.

Inception + Attention

다양한 크기의 특징을 추출한 뒤 어텐션을 적용해 중요한 특징을 강조할 수 있다.

단, 모듈을 추가한다고 항상 성능이 좋아지는 것은 아니다. 데이터셋, 모델 크기, 연산 비용, 학습 방법에 따라 결과가 달라진다.

8. 최종 정리
ResNet: 깊은 네트워크를 효과적으로 학습하기 위한 잔차 연결 구조
SENet: 중요한 특징 채널을 선택적으로 강조하는 어텐션 기법
Inception: 다양한 크기의 필터를 병렬로 사용해 특징을 추출하는 구조
Depthwise Convolution: 채널별 합성곱으로 연산량을 줄이는 기법
CBAM: 채널과 공간적 위치를 함께 고려하는 어텐션 모듈
기억하는 방법
분류	해당 기법
학습 경로 개선	ResNet
채널 중요도 학습	SENet
다양한 크기의 특징 추출	Inception
연산 효율화	Depthwise Convolution
채널과 공간 어텐션	CBAM

핵심: ResNet과 Inception은 주로 네트워크 구조 설계, SENet과 CBAM은 특징 어텐션, Depthwise Convolution은 연산 효율화에 초점을 둔다.
